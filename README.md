# AppMensa

AppMensa is a native Android application developed for a university **Web and Mobile Programming** project.
It was designed to support the main operations of a university cafeteria through a mobile interface, combining user authentication, menu browsing, meal booking, notifications, feedback collection, and support chat features.

## Overview

The project focuses on building a complete Android client for a cafeteria management system.
From the repository structure and codebase, the application includes:

- **user registration and login**;
- **menu browsing** with dish details and nutritional information;
- **meal booking** through category-based dish selection;
- **active bookings and booking history**;
- **news and events** visualization;
- **notifications and feedback management**;
- **in-app support chat**;
- **account actions**, including password update and logout.

The repository mainly contains the **Android client**, while the project context also references a **Flask backend** and an **SQL database** designed as part of the broader system.
